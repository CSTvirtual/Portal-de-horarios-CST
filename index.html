Mantenimiento

Editable directamente desde GitHub

Los profesores y horarios están separados en archivos dentro de datos/. Para activar los botones de edición, escribe la URL de tu repositorio una sola vez en datos/config.js.

Ejemplo: githubRepoUrl: "https://github.com/usuario/repositorio"
